Лабораторная работа 3. Каталог авиационных деталей
Сычева Виктория Сергеевна М8О-101БВ-26

Пакет catalog реализует каталог авиационных деталей. 
Сущность AircraftPart (dataclass) содержит уникальный ID, название, категорию, год производства, производителя и вес в кг. 
Каталог поддерживает добавление, получение, удаление, поиск по категории и имени (без учёта регистра), итерацию в порядке добавления, а также сохранение и загрузку в JSON с контролем версии формата.

Обработка ошибок:
-InvalidEntityError — при создании сущности с нарушением инвариантов (пустой ID, пустое название, недопустимый год ≤1900 или >2026, пустой производитель, вес ≤0). Невалидный объект не попадает в каталог.
-DuplicateIdError — при попытке добавить деталь с уже существующим ID.
-NotFoundError — при get() или remove() несуществующего ID.
-CorruptedFileError — при повреждённом JSON, отсутствии обязательных полей, невалидной детали внутри файла.
-UnsupportedVersionError — при несовпадении format_version с текущей версией.

Память и сложность:
-get(item_id) и __contains__ - через словарь
-add(item) — добавление в словарь и список
-remove(item_id) — из-за удаления из списка
-find_by_category() и find_by_name() линейный проход
Методы поиска возвращают копию списка — внутренний каталог нельзя изменить через результат.
Итерация идёт в порядке добавления.

Хранение:
-JSON-файл содержит поле format_version в корне и массив items.
-Загрузка атомарная: сначала читается в новый каталог, и только при успехе возвращается. При ошибке в середине файла исходный каталог не изменяется.
-При добавлении нового поля в AircraftPart номер версии формата увеличивается.

Ограничения:
-Поиск по имени — подстрока без учёта регистра, точного совпадения нет.
-Поиск по категории — чувствителен к регистру.
-Год ограничен диапазоном 1900–2026.
-Версия формата жёстко задана константой CURRENT_FORMAT_VERSION; миграции между версиями не реализованы.
